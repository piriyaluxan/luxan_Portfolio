# luxan_Portfolio

This repository contains the source code for a personal portfolio website built with Next.js. The site showcases skills, projects, experience, and contact information in a clean, modern layout.

## About this Portfolio

- **Purpose:** Present an online portfolio for a developer/designer to highlight work, experience, and contact details.
- **Built with:** Next.js, TypeScript, Tailwind CSS, and React.
- **Contents:**
  - `app/` — Next.js application source files
  - `public/` — static assets used by the site
  - `README.md` — project overview

## What to expect

- A responsive hero section with a professional introduction
- Experience and skills sections
- Project showcase with highlights
- Contact area for inquiries and networking

## Featured Project

### FitSync — Gym Management Platform

A modern, all-in-one gym management system designed to help fitness businesses streamline operations, manage members, and grow revenue.

**About This Application**

FitSync is a comprehensive SaaS platform built for fitness businesses of all sizes. It provides gym owners and managers with powerful tools to manage every aspect of their fitness business from member management to financial tracking. With an intuitive interface and real-time analytics, FitSync empowers fitness entrepreneurs to focus on what they do best—building thriving fitness communities.

## How to use

1. Install dependencies: `npm install`
2. Run locally: `npm run dev`
3. Visit `http://localhost:3000`

## Notes

This portfolio is intended as a personal showcase and is not a production application for client delivery. It is designed to demonstrate design, development, and front-end presentation skills.
